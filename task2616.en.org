~i+1~, since they form the smallest possible difference. It's important that no index is used more than once.

* COMMENT Dynamic Programming

Let's define ~p~ as an index.

#+begin_src rust :noweb-ref task2616:Actions
  let p = p as usize;
#+end_src

The solution is found recursively in the ~find~ function using dynamic programming. The matrix
~dp[i][x]~ contains the result for the remaining source after index ~i~ for the remaining ~x~ pairs. The result of the problem
is the value ~dp[0][p]~. First, we fill ~dp~ with a special value ~-1~.

It's important that cases ~x=0~, ~i=n-1~, and ~i=n-2~ are special, so for efficiency, the matrix ~dp~ has
a reduced size ~(n-2)x(p-1)~. Therefore, we handle the special case ~p=0~ separately (the result here is ~0~).
