* Замикання

Для кожного курса, який є початковим в мапі залежностей (усі інші курси не будуть досяжними) створимо
транзитивне замикання (=closure=) у вигляді невпорядкованої множини (~HashSet~) за допомогою пошуку в
ширину (=BFS=). Об'єднаємо всі такі замикання у невпорядковану мапу (~HashMap~).

#+begin_src rust :noweb-ref task1462:Декларації
  use std::collections::HashSet;
#+end_src

#+begin_src rust :noweb-ref task1462:Дії
  let mut closures = HashMap::new();
  for from in deps.keys() {
      let mut closure: HashSet<usize> = HashSet::new();
      let mut queue = vec![*from];
      while let Some(to) = queue.pop() {
          closure.insert(to);
          for to in deps.get(&to).unwrap_or(&vec![]) { if !closure.contains(to) { queue.push(*to); } }
      }
      closures.insert(from, closure);
  }
#+end_src
