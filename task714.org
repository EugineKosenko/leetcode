* Пошук

Функція рекурсивного пошуку приймає наступні параметри:

- перелік цін ~prices~;
- розмір транзакційного платежа ~fee~;
- поточний дохід/видаток ~profit~; при цьому видатки кодуються від'ємними значеннями;
- ознака того, що активи куплено ~is_stocked~.

#+begin_src rust :noweb yes :noweb-ref task714:Визначення
  fn find(prices: &[i32], fee: i32, profit: i32, is_stocked: bool) -> i32 {
      <<task714:find:Дії>>
  }
#+end_src

Якщо перелік цін пустий, повертаємо поточний дохід як остаточний результат.

#+begin_src rust :noweb yes :noweb-ref task714:find:Дії
  if prices.is_empty() { return profit; }
#+end_src

Оптимальний результат визначається як максимальне з трьох значень:

- пропуск дії на поточному кроці;
- покупка актива, якщо він ще не куплений (~is_stocked=false~);
- продажа актива, якщо він вже куплений (~is_stocked=true~).

При цьому, однак, можливий тільки один з двох останніх варіантів.

Для простоти вважатимо, що транзакційний платіж береться при купівлі.

#+begin_src rust :noweb yes :noweb-ref task714:find:Дії
  find(&prices[1..], fee, profit, is_stocked)
      .max(if is_stocked {
          find(&prices[1..], fee, profit + prices[0], !is_stocked)
      } else {
          find(&prices[1..], fee, profit - prices[0] - fee, !is_stocked)
      })
#+end_src
