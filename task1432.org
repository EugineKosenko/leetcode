* Пошук рішення

Перетворимо число-джерело на рядок.

#+begin_src rust :noweb-ref task1432:Дії
  let s = num.to_string();
#+end_src

Знайдемо першу цифру.

#+begin_src rust :noweb-ref task1432:Дії
  let d = s.chars().next().unwrap();
#+end_src

Перебираємо усі комбінації цифр, виключаючи комбінацію, де ~d~ замінюється на ~0~, оскільки така заміна
призводить до ведучних нулів у числі.

#+begin_src rust :noweb-ref task1432:Дії
  let (mn, mx) = ('0'..='9').map(|d1| ('0'..='9').filter_map(move |d2| {
      if d1 == d && d2 == '0' { None } else { Some((d1, d2)) }
  })).flatten()
      .map(|(d1, d2)|
           s.chars().map(|d| if d == d1 { d2 } else { d })
           .collect::<String>().parse::<i32>().unwrap())
      .fold((i32::MAX, 0), |(mn, mx), n| (mn.min(n), mx.max(n)));
  mx - mn
#+end_src
