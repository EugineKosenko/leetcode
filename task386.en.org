* Problem Description

The function ~lexical_order~ takes an integer ~n~ and returns all numbers in the range ~[1, n]~ in
lexicographical order. Lexicographical order is the order in which numbers would appear if they were
strings. For example, for ~n=13~, the result would be ~[1,10,11,12,13,2,3,4,5,6,7,8,9]~.

* Solution Approach

We will solve this recursively using a ~find~ function that takes the limit ~n~ and the current value ~i~,
filling the ~result~ sequentially with found values. Thus, it's sufficient to start with an empty result and
call it sequentially for all digits from ~1~ to ~9~, since a number cannot start with ~0~.

#+begin_src rust :noweb yes :noweb-ref task386:Actions
  let mut result = Vec::new();
  for i in 1..=9 { find(n, i, &mut result); }
  result
#+end_src

Let's define the recursive search function itself.

      <<task386:find:Actions>>
  }
#+end_src

If the current value ~i~ is greater than ~n~, further enumeration makes no sense, so we just terminate.

#+begin_src rust :noweb yes :noweb-ref task386:find:Actions
  if i > n { return; }
#+end_src

Add the current value ~i~ to ~result~.

#+begin_src rust :noweb yes :noweb-ref task386:find:Actions
  result.push(i);
#+end_src

Perform recursive search by adding another digit (multiplying by ~10~) and iterating through all possible
digits for the last position.

#+begin_src rust :noweb yes :noweb-ref task386:find:Actions
  for j in 0..=9 { find(n, 10*i+j, result); }
#+end_src
