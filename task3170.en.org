* Problem Description

The function ~clear_stars~ receives a string ~s~ consisting of lowercase English letters and asterisks
(~*~). Each asterisk removes the smallest of the previous characters, if it exists. The function returns
the resulting string after processing all asterisks.

* Solution Approach

We create an ordered bag ~queue~ (~BinaryHeap~) where we store all characters except asterisks
along with their positions. We order the pairs so that the character value increases while its position
decreases.

#+begin_src rust :noweb yes :noweb-ref task3170:Declarations
  use std::collections::BinaryHeap;
  use std::cmp::Reverse;
#+end_src

#+begin_src rust :noweb yes :noweb-ref task3170:Actions
  let mut queue = BinaryHeap::new();
#+end_src

We process each character of the source string ~s~ in sequence. If the current character is an asterisk,
we remove the smallest previous character; otherwise, we add the current character to the queue with its
current index.

#+begin_src rust :noweb yes :noweb-ref task3170:Actions
  for (i, c) in s.bytes().enumerate() {
      if c == b'*' {
          <<task3170:Remove-Character>>
      } else {
          queue.push((Reverse(c), i));

#+end_src

Finally, we iterate through the queue in any order and fill the result. For optimization, we don't change
the character indices during removal, so the result must initially contain space for all possible
indices. Then we remove all "empty" spaces (with ~0~) to compress the result.

#+begin_src rust :noweb yes :noweb-ref task3170:Actions
  let mut result = vec![0; s.len()];
  for (Reverse(c), i) in queue { result[i] = c; }
  let result = result.into_iter().filter(|&c| c != 0).collect();
  String::from_utf8(result).unwrap()
#+end_src

* Character Removal

Choosing a character for removal is simple - it's the first character in the queue if it exists. However,
removing a character from the queue is non-trivial since we would need to decrease the indices of all elements
that come after the chosen character. However, the ordered queue doesn't allow in-place modifications.

Therefore, for efficiency, we leave the indices unchanged, simply popping the next character from the queue.

#+begin_src rust :noweb yes :noweb-ref task3170:Remove-Character
  queue.pop();
#+end_src
