* Пошук максимальної суми

Відповідно до алгоритма, перебираємо елементи масива і будуємо поточну суму ~sum~ і найкращу суму
~best1~.

#+begin_src rust :noweb-ref task1749:Дії
  let mut best1 = i32::MIN;
  let mut sum = 0;
  for n in &nums {
      let n = *n;
      sum = n.max(sum + n);
      best1 = best1.max(sum);
  }
#+end_src

* Пошук мінімальної суми

Повторюємо той саме цикл, але тепер знаходимо мінімальну суму.

#+begin_src rust :noweb-ref task1749:Дії
  let mut best2 = i32::MAX;
  let mut sum = 0;
  for n in nums {
      sum = n.min(sum + n);
      best2 = best2.min(sum);
  }
#+end_src

Оскільки ми обчислюємо абсолютне значення, поміняємо знак результата.

#+begin_src rust :noweb-ref task1749:Дії
  best2 = -best2;
#+end_src

* Отримання результата

Результатом є найбільше з двох значень ~best1~ і ~best2~.

#+begin_src rust :noweb-ref task1749:Дії
  best1.max(best2)
#+end_src
