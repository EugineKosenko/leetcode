* Actions

In the special case where ~m=1~, it's impossible to split the source at all, so we simply return the source as
the result. This case is verified in the [[id:bd0d3ecf-7582-4974-bff5-8b04184fb778]["Solo"]] test.

#+begin_src rust :noweb-ref task3403:Actions
  if m == 1 { return word; }
#+end_src 

For all indices ~i~ from ~0~ to ~n-1~, we iterate through all fragments with index range
~i..n.min(i+n-m+1)~.

#+begin_src rust :noweb-ref task3403:Actions
  (0..n).map(|i| &word[i..n.min(i+n-m+1)]).max().unwrap().to_string()
#+end_src

In this variant, we cannot choose the largest string ~"h"~ because that would mean the source was
