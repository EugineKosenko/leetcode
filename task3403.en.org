* Actions

For indices ~i~, we iterate through all fragments ~i..n.min(i+n-m+1)~. Interestingly, for the special case
~m=1~, we can only use ~i=0~, since for one player it's impossible to split the source into multiple
fragments. If ~m>1~, we need to iterate through all ~i~ from ~0~ to ~n~.

#+begin_src rust :noweb-ref task3403:Actions
  (0..if m == 1 { 1 } else { n })
      .map(|i| &word[i..n.min(i+n-m+1)]).max().unwrap().to_string()
#+end_src

** "Pair"

An interesting case that fails when we only iterate through distributions for the first ~m~ values of the
initial index ~i~.
