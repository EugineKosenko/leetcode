* Отримання статистики

Отримаємо статистику (кількість символів) у вигляді невпорядкованих мап (~HashMap~) в обох словах.

#+begin_src rust :noweb-ref task1657:Декларації

#+end_src

#+begin_src rust :noweb-ref task1657:Дії
  let mut s1: HashMap<char, usize> = HashMap::new();
  for c in word1.chars() { *s1.entry(c).or_default() += 1; }
  let mut s2: HashMap<char, usize> = HashMap::new();
  for c in word2.chars() { *s2.entry(c).or_default() += 1; }

* Порівняння ключів

Обидва слова мають мати однакові набори символів. Тому перетворимо ключі статистик на невпорядковані
множини і порівняємо їх. Якщо ці множини не співпадають, перевірка очевидно невдала.

#+begin_src rust :noweb-ref task1657:Декларації
  use std::collections::HashSet;
#+end_src

#+begin_src rust :noweb-ref task1657:Дії
  let ks1: HashSet<_> = s1.keys().collect();
  let ks2: HashSet<_> = s2.keys().collect();
  if ks1 != ks2 { return false; }
#+end_src

порівняємо ці сумки поелементно за вказаним порядком.

#+begin_src rust :noweb-ref task1657:Декларації

#+begin_src rust :noweb-ref task1657:Дії
  let mut s1: BinaryHeap<_> = s1.into_values().collect();
