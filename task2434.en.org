* Statistics collection

We'll collect in an ordered map (~BTreeMap~) ~cnts~ the count of each letter in the source string ~s~. An
ordered map is needed here because the algorithm compares the top letter of the stack with the smallest
letter in the remaining string.

#+begin_src rust :noweb-ref task2434:Declarations
  use std::collections::BTreeMap;
#+end_src

#+begin_src rust :noweb-ref task2434:Actions
  let mut cnts: BTreeMap<_, usize> = s.chars()
      .fold(BTreeMap::new(), |mut cnts, c| { *cnts.entry(c).or_default() += 1; cnts });
#+end_src

* Letter processing

We'll process all letters ~c~ from the source string one by one. Each such symbol will be distributed
between the paper result (~result~) and the intermediate stack ~t~. At the end, the stack automatically
becomes empty.

#+begin_src rust :noweb yes :noweb-ref task2434:Actions
  let mut result = String::new();
  let mut t = Vec::new();
  for c in s.chars() {
      <<task2434:Process-letter>>
  }
  result
#+end_src

We place the current letter ~c~ into ~t~.

#+begin_src rust :noweb yes :noweb-ref task2434:Process-letter
  t.push(c);
#+end_src

We'll decrease the count of letter ~c~ in the statistics, and if the count becomes zero, we remove this
record completely.

#+begin_src rust :noweb yes :noweb-ref task2434:Process-letter
  ,*cnts.get_mut(&c).unwrap() -= 1;
  if *cnts.get_mut(&c).unwrap() == 0 { cnts.remove(&c); }
#+end_src

After this, while ~t~ is not empty and the top letter of ~t~ is not greater than any letter in the
remaining ~s~, i.e., not greater than the smallest key in ~cnt~, we pop this letter and add it to the
result. For empty statistics, we assume it still contains the largest letter ~z~, which will lead to
popping all remaining letters in ~t~.

#+begin_src rust :noweb yes :noweb-ref task2434:Process-letter
  while !t.is_empty() && t.last().unwrap() <= cnts.first_key_value().map(|k| k.0).unwrap_or(&'z') {
      result.push(t.pop().unwrap());
  }
#+end_src
