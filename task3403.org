* Дії

Для індексів ~i~ перебираємо усі фрагменти ~i..n.min(i+n-m+1)~. Цікавим є те, що для особливого випадка
~m=1~ ми можемо використовувати тільки ~i=0~, оскільки для одного гравця неможливо розбити джерело на
декілька фрагментів. Якщо ж ~m>1~, то треба перебрати усі ~i~ від ~0~ до ~n~.

#+begin_src rust :noweb-ref task3403:Дії
  (0..if m == 1 { 1 } else { n })
      .map(|i| &word[i..n.min(i+n-m+1)]).max().unwrap().to_string()
#+end_src
